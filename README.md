## Installation and Usage

Prerequisites: [Node.js](https://nodejs.org/en/) (`^8.10.0`, `^10.13.0`, or `>=11.10.1`), npm version 3+.

You can install ESLint using npm:

```
$ npm install eslint --save-dev
```
